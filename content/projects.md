## LLM-Powered Robotic Task Planning

Personal project translating natural-language commands into executable ROS2 actions for a simulated robotic arm in Gazebo.

**Focus:** LLM planning, ROS2 action execution, Gazebo simulation, robotics autonomy.

## Human Follower Mobile Robot

Course project for real-time human tracking and following. Built a vision-based data pipeline from an Android device to a microcontroller for navigation.

**Focus:** Computer vision, real-time tracking, embedded communication, mobile robotics.

## Exoskeleton Robot Control Systems

Designed and implemented control systems for rehabilitation and exoskeleton robots at FUM CARE, including fuzzy logic, PID, and intelligent control approaches.

**Focus:** ROS2, MATLAB Simscape, C++, Python, Raspberry Pi, motor and sensor integration.

## Robotic Intelligent Solar Shade

Built an Arduino-based two-axis system for solar tracking and controlled shade concentration over a target area.

**Focus:** Arduino, control systems, prototyping, sensor-driven actuation.

## Current Research

My current graduate research investigates risk-aware planning and control for quadruped robots under uncertain interaction with the environment. The stack combines deep reinforcement learning, Isaac Gym, simulation-based data collection, and cloud-based training.
