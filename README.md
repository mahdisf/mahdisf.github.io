# Mahdi Sarfarazi — Personal Blog

This repository hosts my personal website and technical blog, built with **Hugo** using the **PaperMod** theme.

## Features

- Multilingual content (English + Persian)
- Technical posts on **AI**, **robotics**, **ROS2**, simulation, and control
- Custom Hugo outputs (e.g., `llms` plain-text feed)

## Live site

- GitHub Pages (see: this repo’s Pages setting)

## Tech stack

- Hugo (static site generator)
- PaperMod theme
- Markdown content under `content/`

## Project structure

- `content/` — blog posts and site pages (source)
- `themes/` — theme code (PaperMod)
- `hugo.yaml` — Hugo configuration (languages, menus, site params)
- `public/` — generated site output (HTML/CSS/JS). Safe to delete/regenerate.

## Local development

1. Install Hugo
2. From this directory, run:

   ```bash
   hugo server -D
   ```

3. Open the displayed local URL in your browser.

## Deployment

Commit content/config changes, then build and publish the generated site.

> Note: `public/` is normally generated by Hugo; do not manually edit files inside it.
